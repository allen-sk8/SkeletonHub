## 一、離線認人（實驗一）

### 做法
新檔 `preprocessors/track_person_offline.py`（`track_person.py` 沒改，舊的 `--target lock` 照常可用，用來比對）。它讀舊版已存的追蹤結果（`tracks.txt`）、偵測快取（`detections_medium.npz`）與鏡頭切換點，不重跑偵測與追蹤：
1. 用切換點把影片切成鏡頭；每條追蹤軌跡在切換點切開。
2. 每條軌跡用偵測框**往前也往後**接到鏡頭邊界（框重疊比例至少 0.3、框高變化不超過 1.5 倍、最多連續 2 幀沒對上；碰到別人的軌跡就停）。追蹤器沒追到的偵測框另外拼成軌跡。
3. 認人：主角挑法和舊版相同；每條軌跡在**整段長度上平均取 8 張**算外觀（舊版只取 4 張），和主角的 16 張比平均相似度，門檻和舊版一樣（0.6，大而居中的人 0.55）。
   相似度 0.7 以上的軌跡加入主角的比對樣本，再算一次，兩次取高的。
4. 填框順序：先放各軌跡追蹤器本來追到的幀，再放往前往後延伸出的幀，最後放另外拼的軌跡，後放的只能補空位。

第一版沒有第 4 步的順序（全部照相似度高低放），在 456 號出現兩處認錯：一條延伸段接到觀眾、一條只靠偵測框拼出的軌跡是觀眾（相似度 0.663，比選手自己的 0.654 還高）。改成上面的順序後這兩處消失。**相似度本身分不開這位觀眾和選手，現在靠的是填框順序。**

## 三、解析度：縮一半對原解析度（實驗三）

### 做法
新檔 `scripts/finefs_v2_gvhmr_dual.py`：每支影片同時開兩個解碼（原解析度、和 gvhmr_fast 相同的縮一半），一起讀。每段鏡頭：
- 相機轉動（SimpleVO）只在縮一半的畫面上算一次，兩個版本共用，所以**兩版只差選手裁切從哪裡來**，相機估計的隨機性不會混進比較。
- 縮一半版 = 原本的 gvhmr_fast（fp16、不做翻轉測試）；原解析度版用同一個框、同樣 256×256 裁切，抗鋸齒模糊照來源解析度調整。
- 兩版各自跑 ViTPose-H、HMR2、GVHMR。框用最後採用的「外觀辨識開啟＋離線認人」。

### 指標（都不是誤差，沒有真值）
- 2D 信心：ViTPose 17 點信心平均。
- 重投影貼合：SMPL 關節投回畫面，和該版自己的 2D 點（12 個四肢點、信心至少 0.5）的距離，以框高百分比表示，取每支中位數。SMPL 和 COCO 的關節定義本來就不同（例如髖），所以有固定偏差，只看兩版的相對差。另外也和「另一版的 2D 點」比（交叉貼合），避免只是自己和自己對得好。
- 3D 抖動：相機座標 24 關節的加速度平均（m/s²，只在每段內算）。2D 抖動：2D 點加速度（框高百分比／幀²）。
